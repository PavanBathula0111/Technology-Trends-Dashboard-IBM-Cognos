# Technology Trends Dashboard - IBM Cognos

## Project Overview
This project analyzes developer survey data using IBM Cognos Analytics. The dashboards provide insights into demographics, current technology usage, and future technology trends among software developers.

## Dashboards

### 1. Demographics Dashboard
- Age Distribution of Survey Respondents
- Survey Respondents by Country
- Distribution of Respondents by Education Level
- Age Distribution by Education Level

### 2. Current Technology Usage Dashboard
- Top 10 Programming Languages Used
- Top 10 Databases Used
- Top 10 Platforms Used
- Top 10 Web Frameworks Used

### 3. Future Technology Trends Dashboard
- Top 10 Programming Languages Desired
- Top 10 Databases Desired
- Top 10 Platforms Desired
- Top 10 Web Frameworks Desired

## Tools Used
- IBM Cognos Analytics
- Python
- Pandas
- GitHub

## Dataset
Survey data containing developer demographics, technology usage, and technology preferences.
